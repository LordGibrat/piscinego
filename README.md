# Piscine Go

A collection of Go programming exercises and small command-line experiments. The repository includes functions for strings, numbers, recursion, printing, and basic algorithms, plus a few standalone programs.

## Repository guide

- Root-level `.go` files are individual exercises; many define functions intended to be checked separately.
- Subdirectories such as `flags/` contain standalone programs.
- [`GITEA_WORKFLOW.md`](GITEA_WORKFLOW.md) records the project's Git workflow notes.

## Work locally

Install a Go version compatible with [`go.mod`](go.mod), clone the repository, and open the exercise you want to study. Run or test an individual exercise in its intended context; the root directory is a collection of solutions, not one executable application.

This is a learning archive. Files may represent different attempts or stages of an exercise, so review the relevant source before reusing it in another project.
