# Gitea Workflow

This repository is mirrored from the Tomorrow School course repository:

https://01.tomorrow-school.ai/git/gisagadat/piscinego

New course tasks should be completed and committed in Gitea first. GitHub is a public mirror for portfolio visibility and backup. After committing a new task in Gitea, update this mirror with:

```bash
git fetch origin
git push github main
```

The original Gitea history is preserved in this repository.
